🏡 Auberge — Site Web (Work in Progress)


📌 Présentation

Ce projet est le développement du site web d'une auberge.

L'objectif actuel est de présenter une première version du design de la page d'accueil.
Il s'agit d'une maquette fonctionnelle encore en cours d'évolution.

🚧 État actuel du projet

Le projet est en cours de développement.



✅ Actuellement

Page d'accueil construite

Structure globale en place

CSS implémenté

Routing configuré



🔜 À venir


Remplacement des photos temporaires

Choix et intégration de la police et couleurs définitive

Ajustement des tailles typographiques

Traductions complete en :

🇫🇷 Français

🇬🇧 Anglais

🇪🇸 Espagnol

Optimisation du code, des performances, de l'accessibilité et du SEO

Connexion du formulaire de contact



🎨 À propos du design

La police n'a pas encore été choisie

Les tailles de texte sont provisoires

Les photos et videos utilisées ne sont pas définitives

Le design final dépendra fortement du choix typographique et des contenus définitifs.



🛠️ Stack technique

Le projet est développé avec :

Vite

React

SCSS

React Router DOM

Motion

Swiper

i18n



🌍 Internationalisation

L'architecture est prévue pour supporter plusieurs langues.
Les traductions seront intégrées une fois les contenus validés.



📸 Images

Les images présentes sont temporaires.
Des visuels définitifs seront intégrés ultérieurement.



🔄 Évolution du projet

Ce projet évoluera progressivement selon les besoins et retours du client.



💬 Remarques

Ce dépôt présente une version de travail destinée à poser les bases visuelles et structurelles du futur site.
